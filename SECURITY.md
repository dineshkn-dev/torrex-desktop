# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| 0.3.x   | Best effort |
| 0.1.x   | No        |

## Reporting a vulnerability

Email security reports to the maintainers via GitHub Security Advisories (preferred) or open a private security advisory on the repository when published.

Please include:

- Description and impact
- Steps to reproduce
- Affected version and platform

We aim to acknowledge within 72 hours and provide a fix timeline for confirmed issues.

## Safe use

Torrin is a BitTorrent **tool**. Users are responsible for complying with applicable laws and rights when downloading or sharing content.
