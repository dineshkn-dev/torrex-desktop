# Torrin 0.3.0 — macOS

Open-source **BitTorrent client for macOS**, built with **Qt 6 Quick** and **libtorrent 2.x**: fast-resume, modern list UX, no ads, no bundled telemetry.

![Torrin dark mode](https://raw.githubusercontent.com/dineshkn-dev/torrin/main/docs/assets/torrin-dark.png)

## What's new

- **Search** the torrent list by name, info hash, or save path
- **Sort** by name or date created (ascending / descending)
- **ETA** in list rows; **pause all** / **resume all** in the list menu
- **Reveal in Finder** and **copy magnet link** from row and detail menus
- **Keyboard shortcuts:** Find, Space (pause/resume), Delete (remove)
- **Free space** on the download volume in the status bar
- **Resizable** master–detail split; improved narrow-layout behavior
- **AMOLED-style dark** appearance and refreshed list toolbar

## Install

1. Download **Torrin-0.3.0-macos.dmg** (or the asset for your architecture) below.
2. Open the disk image and drag **Torrin** to **Applications**.
3. If macOS shows an unidentified-developer warning, open **System Settings → Privacy & Security** and choose **Open Anyway**. Notarized installs are planned for v1.0.

## Verify downloads

Release artifacts include **SHA-256** checksums, an **SPDX SBOM**, and **cosign** signatures — see files attached to this release.

## Platform

**macOS only** for this release (Apple Silicon and Intel builds per CI). Windows and Linux are on the [roadmap](https://github.com/dineshkn-dev/torrin/blob/main/docs/planning/FUTURE.md#cross-platform).
