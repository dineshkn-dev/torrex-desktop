# Torrin 1.0.0

Open-source **BitTorrent client** for **macOS**, **Windows**, and **Linux**, built with **Qt 6 Quick** and **libtorrent 2.x**: fast-resume, modern list UX, no ads, no bundled telemetry.

![Torrin dark mode](https://raw.githubusercontent.com/dineshkn-dev/torrin/main/docs/assets/torrin-dark.png)

## What's new in 1.0

- **Windows** portable `.zip` (x64) and **Linux** portable `.tar.gz` (x64) alongside macOS `.dmg`
- **CI** builds and tests on macOS, Windows, and Linux on every `main` push and PR
- Platform labels: **Reveal in Finder**, **Reveal in File Explorer**, **Open save folder**
- Everything from **0.3**: list search/sort, ETA, pause/resume all, shortcuts, resizable UI, dark theme

## Install

| Platform | Asset |
|----------|--------|
| macOS | `Torrin-1.0.0-macos-<arch>.dmg` — open and drag **Torrin** to **Applications** |
| Windows | `Torrin-1.0.0-windows-x64.zip` — extract and run `torrin.exe` |
| Linux | `Torrin-1.0.0-linux-x64.tar.gz` — extract and run `torrin` (see README for distro deps) |

On macOS, if you see an unidentified-developer warning, use **System Settings → Privacy & Security → Open Anyway**. Notarized installs are planned for a future release.

## Verify downloads

Release artifacts include **SHA-256** checksums, an **SPDX SBOM** (macOS), and **cosign** signatures — see files attached to this release.
