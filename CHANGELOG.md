## [0.1.0] - 2026-05-22

### Added

- Phase 0: project scaffold, governance docs, CI skeleton
- Phase 1–2: magnet / `.torrent` add, pause, resume, remove
- Phase 3: master-detail UI with filters and torrent detail tabs
- Phase 4: Settings (bandwidth, port, DHT/UPnP), fast-resume across restarts
- Phase 5: macOS `.app` / `.dmg` packaging, SPDX SBOM, cosign-signed release workflow
- `torrex_core` libtorrent session on a worker thread (no Qt in core)
- Minimal Qt Quick shell UI (Basic style, system light/dark)
